# Accessibility

Saans targets WCAG 2.2 level AA. Each criterion below names how the app meets it and the test that
keeps it that way. Tests live next to the code and run in CI.

| WCAG criterion                  | How                                                                                                                                         | Where                                                                                                                                                                   | Checked by                                      |
| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------- |
| 1.1.1 Non-text content          | The chart has a text label and a full table of every hour; the logo is decorative (`alt=""`)                                                | [ForecastStrip.svelte](web/src/components/ForecastStrip.svelte), [App.svelte](web/src/App.svelte)                                                                       | `draws 48 hours with a table alternative`       |
| 1.3.1 Info and relationships    | Landmarks (header, main, footer), headings per section, fieldsets with legends, labelled controls, a real table with column headers         | all components                                                                                                                                                          | axe on every component and the app              |
| 1.4.1 Use of colour             | Every band is shown by name and number; the cleanest window is outlined, not only coloured                                                  | [AirNow.svelte](web/src/components/AirNow.svelte), [format.ts](web/src/lib/format.ts)                                                                                   | `names the band in words`                       |
| 1.4.3 Contrast (text)           | All text pairs at least 4.5:1 in light and dark themes                                                                                      | [app.css](web/src/app.css)                                                                                                                                              | [contrast.test.ts](web/src/contrast.test.ts)    |
| 1.4.11 Non-text contrast        | Band colours at least 3:1 against the card in both themes; focus ring 3 px                                                                  | [app.css](web/src/app.css)                                                                                                                                              | [contrast.test.ts](web/src/contrast.test.ts)    |
| 1.4.4, 1.4.10 Resize and reflow | Relative units, one column below 60 rem, no horizontal scroll at 320 px                                                                     | [app.css](web/src/app.css)                                                                                                                                              | manual check at 390 px and 200 % zoom           |
| 2.1.1 Keyboard                  | Native buttons, inputs and `details`; no custom key handling to break                                                                       | all components                                                                                                                                                          | axe                                             |
| 2.4.1 Bypass blocks             | Skip link to the main content                                                                                                               | [App.svelte](web/src/App.svelte)                                                                                                                                        | axe on the app                                  |
| 2.4.3 Focus order               | After choosing a place the focus moves to the section heading instead of being lost                                                         | [PlaceSearch.svelte](web/src/components/PlaceSearch.svelte)                                                                                                             | `lists Indian matches and selects one`          |
| 2.4.7 Focus visible             | A 3 px outline on every focusable element                                                                                                   | [app.css](web/src/app.css)                                                                                                                                              | manual check                                    |
| 2.5.8 Target size               | Buttons and inputs at least 44 px tall                                                                                                      | [app.css](web/src/app.css)                                                                                                                                              | manual check                                    |
| 3.3.1, 3.3.3 Errors             | AI and network failures appear as alerts with a Retry button; the count fields state their range (0 to 12)                                  | [PlanPanel.svelte](web/src/components/PlanPanel.svelte), [HouseholdForm.svelte](web/src/components/HouseholdForm.svelte)                                                | `offers a retry`, `describes the allowed range` |
| 4.1.3 Status messages           | Search results, "Writing your plan", "Today's plan is ready" and "Asking Gemini" are announced through status regions that stay in the page | [PlaceSearch.svelte](web/src/components/PlaceSearch.svelte), [PlanPanel.svelte](web/src/components/PlanPanel.svelte), [AskBox.svelte](web/src/components/AskBox.svelte) | `1 place found`, `Today's plan is ready`        |

Also: light and dark themes follow the system setting, Windows high contrast mode keeps the chart
readable with system colours (`forced-colors`), motion is limited when reduced motion is requested,
and the page explains in a `noscript` note that it needs JavaScript.
